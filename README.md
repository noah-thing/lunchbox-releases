# Lunchbox releases

Installers for [Lunchbox](https://github.com/noah-thing/lunchbox) and the feed the app reads for updates and messages. Download the latest version under [Releases](https://github.com/noah-thing/lunchbox-releases/releases/latest).

`notices.json` is signed. The app ignores it unless the signature matches the key built into Lunchbox.
